# Diseño

Prototipo de alta fidelidad de la vista del estudiante, usado como referencia
visual para construir las pantallas con Next.js y Tailwind CSS.

| Carpeta | Contenido |
|---|---|
| [`prototipo/`](prototipo/) | Archivos fuente del prototipo (`.dc.html`) y la correspondencia de cada pantalla con su ruta en el sistema. Requieren el visor de la herramienta de diseño; en GitHub se ven como código. |
| [`capturas/`](capturas/) | Imágenes de cada pantalla para verlas directamente. |
